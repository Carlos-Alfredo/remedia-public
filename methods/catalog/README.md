# Flag → action catalog

Exported from the RemedIA DTP catalog used in the locked evaluation.

- `primary_action`: verb stamped for generation (first allowlist entry).
- `allowed_actions`: pipe-separated allowlist; generation locks to the stamped primary in the rated runs.
- `defer_to_prm`: when primary is `none`, optional later PRM that owns the problem.

Manuscript pointer: full flag mappings archived in remedia-public.
