# Evaluation aggregates

Canonical numbers for the manuscript Results section.

| Path | Role |
|------|------|
| `derived/rows_remedia.csv` · `rows_baseline.csv` | One graded recommendation per row |
| `derived/gaps.csv` | Specialist-noted gaps |
| `handoffs/` | Recommendations that use an earlier acceptance in the same note (script, candidates, decisions, summary) |
| `tables/` | Aggregates (overall, by action, by case, FPs, DTP/flag) |
| `charts_data/` | Convenience subset of `tables/` for plotting — **same figures; prefer `tables/`** |
| `specialist_analysis_pt.md` | Portuguese narrative analysis (matches the locked grades) |
| `case_report_pt.md` | Portuguese per-case comparison notes |

Primary workbooks live in `../specialist_workbooks/`.
